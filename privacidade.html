Privacy Policy – “diario do Pedro publicador”

Last updated: November 25, 2026

“diario do Pedro publicador” is a private, internal tool used only by the owner of the YouTube channel diário do Pedro (@diariodopedrooficial) to upload and schedule his own videos on his own channel. It is not offered to the public and has no other users.

What the tool accesses (YouTube API Services)

  • youtube.upload: to upload the channel owner’s own videos and thumbnails, with title, description and scheduled publish time.
  • youtube.readonly: to read the authorized channel’s name, handle and basic statistics, only to confirm that the tool is connected to the correct channel before uploading.

The tool does not read, collect or process data from any other YouTube user, viewer, comment or channel.

How data is stored

The OAuth authorization token is stored only on the channel owner’s own computer, in a local file that is never shared or uploaded anywhere. No YouTube data is stored on servers, sold, shared with third parties or used for advertising. A small local record of each upload (video ID, link and upload time) is kept on the same computer for the owner’s own production notes.

Third parties

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google’s handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account › Security › Third-party access. Revoking access, or deleting the local token file, removes all access of the tool to the channel.

Contact

Questions about this policy: send a direct message to @diariodopedro_ia on Instagram.
